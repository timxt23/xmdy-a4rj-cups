XMDY A4RJ Printer Driver @VERSION@

Open-source CUPS driver for XMDY / HZTZ A4RJ portable A4 thermal printers (GD-88 family), USB and Bluetooth.

Installs:

  • /Library/Printers/XMDY-A4/ — filter, queue setup and uninstall scripts
  • /Library/Printers/PPDs/Contents/Resources/XMDY A4RJ*.ppd
  • /Library/LaunchAgents/io.github.timxt23.xmdy-btd.plist — starts the Bluetooth bridge app “XMDY Bluetooth”

If the printer is connected and powered on, a print queue XMDY_A4 is created automatically. Otherwise add the printer later in System Settings → Printers & Scanners.

Bluetooth: turn the printer on, run /Library/Printers/XMDY-A4/xmdy-btpair (as your user), then sudo /Library/Printers/XMDY-A4/setup-queue.sh --bluetooth and allow “XMDY Bluetooth” to use Bluetooth. If the printer is already paired, the queue XMDY_A4_BT is created automatically.

To uninstall: sudo /Library/Printers/XMDY-A4/uninstall.sh
