# Драйвер CUPS для XMDY A4RJ на macOS

Драйвер CUPS с открытым кодом для портативных A4-термопринтеров **XMDY / HZTZ A4RJ**.
Они продаются под разными брендами, драйверы производителя относятся к семейству «GD-88».
Печать из любого приложения macOS через ⌘P **по USB или Bluetooth**.

[English](README.md) · [Описание протокола (англ.)](PROTOCOL.md)

- Нативный универсальный бинарник для Apple Silicon и Intel. В отличие от драйвера производителя, Rosetta не нужна.
- Плотность печати действительно меняется. У производителя эта опция в диалоге есть, но ни на что не влияет.
- Исправлена ошибка драйвера производителя, из-за которой очередь останавливалась после каждого задания
  («Unable to send data to printer»).
- Режим «фото» (диффузия ошибки), негатив, зеркальная печать, обрезка пустого места для рулона,
  бумага с метками, настраиваемая подача.
- Печать по Bluetooth, которую производитель на macOS не поддерживает. В комплекте утилита
  сопряжения, потому что в «Системных настройках» у этого принтера нет кнопки «Подключить».
- Настройки в диалоге печати на русском языке.

## Установка

1. Скачайте `XMDY-A4RJ-<версия>.pkg` из [Releases](../../releases) или соберите сами (см. ниже).
2. Пакет **не подписан**, поэтому при первом запуске macOS его заблокирует. Откройте пакет, нажмите «Готово»,
   затем зайдите в **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»**.
3. Перед установкой подключите принтер по USB и включите его. Тогда установщик сам создаст очередь **XMDY_A4**.
   Если принтер не был подключён, добавьте его позже в **Системных настройках → Принтеры и сканеры**
   (драйвер «XMDY A4RJ» выберется автоматически) или выполните:

   ```sh
   sudo /Library/Printers/XMDY-A4/setup-queue.sh
   ```

## Bluetooth

1. Включите принтер и отключите его от телефонов: по Bluetooth принтер принимает только одно соединение.
2. Выполните сопряжение от своего пользователя, без sudo. macOS может попросить разрешить
   Терминалу доступ к Bluetooth.

   ```sh
   /Library/Printers/XMDY-A4/xmdy-btpair
   ```

   В «Системных настройках» принтер виден в разделе «Устройства поблизости», но кнопки
   «Подключить» у него нет. Поэтому и нужна эта утилита.
3. Создайте очередь **XMDY_A4_BT**:

   ```sh
   sudo /Library/Printers/XMDY-A4/setup-queue.sh --bluetooth
   ```

   macOS спросит, разрешить ли **«XMDY Bluetooth»** использовать Bluetooth. Нажмите **«Разрешить»**.
   Позже это можно проверить или изменить в «Системных настройках → Конфиденциальность и безопасность → Bluetooth».

Подключать принтер вручную не нужно. Очередь отправляет задания локальному мосту
(`socket://127.0.0.1:9101`, он доступен только с этого Mac). Мост — это фоновое приложение
«XMDY Bluetooth» без окна, его по запросу запускает агент launchd в вашей сессии. Приложением
он сделан потому, что macOS даёт доступ к Bluetooth только приложениям, которые разрешил пользователь,
а системным службам не даёт вовсе. Для каждого задания мост сам
открывает Bluetooth-соединение, ждёт, пока принтер подтвердит печать каждой страницы, и закрывает
соединение. Если принтер выключен, задание ждёт до 30 минут и печатается, когда принтер включат. Чтобы беречь
батарею, интервал между попытками подключения растёт с 10 секунд до 2 минут. Когда печати нет,
процесс моста вообще не запущен.
Одна страница печатается около 26 секунд, как и из приложения на телефоне.

## Удаление

```sh
sudo /Library/Printers/XMDY-A4/uninstall.sh
```

Команда удаляет все очереди, которые используют драйвер, Bluetooth-мост, установленные файлы
и запись о пакете. Bluetooth-сопряжение остаётся, его можно удалить в «Системных настройках → Bluetooth».

## Настройки печати

| Настройка | Значения | По умолчанию |
|---|---|---|
| Плотность печати (`XmdyDensity`) | Светлая / Обычная / Тёмная / Очень тёмная (`0`–`3`) | Обычная |
| Порог чёрного (`XmdyThreshold`) | `96` `128` `160` `192` (больше — жирнее) | `128` |
| Полутона (`XmdyDither`) | Текст и графика / Фото | Текст и графика |
| Негатив, Зеркально | Вкл / Выкл | Выкл |
| Тип бумаги (`XmdyMediaType`) | Рулон / Фальцованная с метками / Тату | Рулон |
| Не печатать пустое место внизу (`XmdyTrim`) | Вкл / Выкл | Выкл |
| Сдвиг по горизонтали, мм (`XmdyOffsetX`) | −5…+5 | 0 |
| Подача перед документом / после страницы / после документа, мм | | 0 / 0 / 12 |
| Размер бумаги | A4, A5, B5, Letter, Legal | A4 |

Из командной строки:

```sh
lp -d XMDY_A4 -o XmdyDensity=2 -o XmdyDither=Diffusion фото.jpg
lpoptions -p XMDY_A4 -o XmdyDensity=2      # изменить значение по умолчанию для очереди
```

## Сборка

```sh
make && make test && make pkg     # build/XMDY-A4RJ-<версия>.pkg
```

## Если что-то не печатает

- **Очередь остановилась, «Unable to send data to printer»**: принтер был выключен или спал. Задания повторяются
  автоматически. Чтобы запустить очередь сразу, выполните `cupsenable XMDY_A4`.
- **Подробный лог**: включите его командой `sudo cupsctl --debug-logging`, отправьте задание на печать и смотрите
  `/var/log/cups/error_log`.
- **Лог Bluetooth-моста**:
  `/usr/bin/log show --last 1h --predicate 'subsystem == "io.github.timxt23.xmdy"'`.
  Путь `/usr/bin/log` нужен полностью: в zsh `log` — встроенная команда оболочки.
- **Задание по Bluetooth не печатается**: проверьте, что принтер включён и не подключён к телефону,
  а «XMDY Bluetooth» разрешён в «Конфиденциальность и безопасность → Bluetooth». Затем снова запустите
  `xmdy-btpair`. Для печати по Bluetooth нужен пользователь, вошедший в систему.
